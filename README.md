# Scale-Normalized Nonconformity Scoring for Conformal Fault Detection in Chemical Processes

Fault detection in chemical processes must catch faults reliably while keeping the false alarm rate (FAR) low. Principal component analysis (PCA) assumes linear, Gaussian behavior that often fails in practice; autoencoders relax this but score each variable’s reconstruction error on its raw scale, letting high-variance variables mask faults in low-variance channels. This work proposes a scale-normalized nonconformity score for conformal fault detection, computed from a temporal convolutional network autoencoder (TCN-AE). Three scores are compared: mean squared error (MSE), maximum per-variable error (MaxPV), and a scale-normalized maximum (NormMaxPV) that divides each variable’s error by its calibration variance. Conformal prediction calibrates each score at significance level 0.01, bounding FAR at 1%. On the Tennessee Eastman benchmark, across 20 fault types and five seeds, NormMaxPV reaches an average detection rate of 83.5%, against 61.9%–70.6% for PCA and dense-autoencoder baselines (p < 0.001). A four-architecture ablation attributes the gain mainly to the score: a conventional convolutional autoencoder matched to the TCN-AE’s parameter count becomes statistically indistinguishable from it once both use NormMaxPV (p = 0.79), and the TCN-AE matches the best alternative’s accuracy with about one-tenth the parameters, with FAR at or below 1% throughout.
